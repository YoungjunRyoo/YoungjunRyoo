# 🚀 Featured Projects

## 🏠 Rent Mate

**React · Next.js · Prisma · PostgreSQL · NextAuth**

A full-stack room rental and roommate matching platform with multi-criteria search, authenticated favorites, user profile management, and interactive map-based rental discovery.

### Key Features

- Multi-criteria rental property search
- Roommate matching based on location, budget, and preferences
- Authenticated favorites
- User profile management
- Interactive map with custom price markers
- Synchronized map and listing interactions

---

## ⚾ Dallas Monsters Baseball Team App

**React Native · Firebase · Expo**

A mobile baseball team management application designed for roster management, lineup operations, game records, player statistics, and team notifications.

### Key Features

- Role-based admin and player workflows
- Roster approval and management
- Lineup management
- Real-time Firestore synchronization
- Game record persistence
- Season statistics and player leaderboards
- Expo push notifications
- iOS and Android support

---

## ⚾ My Player

**React · Firebase Authentication · Cloud Firestore · MLB Stats API**

An MLB analytics and player-tracking web application that provides schedules, standings, player statistics, league leaders, news, and personalized player favorites.

### Key Features

- MLB player search
- Game schedules
- League standings
- Statistical leaders
- Recent player performance
- Position-specific player analytics
- Google authentication
- Persistent user favorites
- MLB API integration
